METEO FLASKIO ANDROID 1.1
Tre widget Android reali:
- 2x1: temperatura, condizioni, min/max
- 4x2: aggiunge previsioni, umidità e vento
- 4x3: aggiunge qualità aria, AQI e indicatore di rischio grandine

DATI
Previsioni e qualità aria: Open-Meteo, senza API key.
Posizione iniziale: Roma/Aurelio (coordinate approssimative).
Aggiornamento richiesto dal widget: ogni 30 minuti (Android può differirlo per risparmio energetico).
Tocco sul widget: apre Meteo Flaskio.

NOTA GRANDINE
Il rischio grandine del widget è un indicatore euristico basato su temporali, CAPE e probabilità di precipitazione.
Non è un'allerta ufficiale. Le allerte ufficiali vanno verificate presso la Protezione Civile.

COMPILAZIONE
Apri MeteoFlaskioAndroid in Android Studio, attendi Gradle Sync, poi Build > Build APK(s).
